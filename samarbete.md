# Samarbete
## Gemensamt repository

Med hjälp av ett gemensamt repository kan teamet samla sina gemensamma filer och koder på en gemensam plats.

De medlemmmar som delar projektet och repositoryt kan göra commits och pusha sina ändringar till repot. Det gör det lättare för att kunna samarbete, dela kod och se projektets versionhistorik.
